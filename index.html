☁️ https://openclassreport.pages.dev 배포 상세 가이드

🎉 원하는 도메인: https://openclassreport.pages.dev
*.pages.dev는 Cloudflare Pages 서비스의 기본 무료 도메인 형식입니다. Cloudflare에서 프로젝트 이름을 openclassreport로 등록하시면 추가 비용 없이 영구적으로 해당 주소를 사용하실 수 있습니다.
방법 1: 직접 업로드 (가장 추천, 1분 안에 완료)
  1. Cloudflare 접속: https://dash.cloudflare.com 에 로그인 (무료 가입 가능)
  2. Pages 생성: 왼쪽 메뉴에서 Workers 및 Pages (Workers & Pages) → 만들기 (Create application) 클릭 후 Pages 탭 선택
  3. 자산 업로드: 자산 직접 업로드 (Upload assets) 선택
  4. 프로젝트 이름 입력: 반드시 openclassreport 로 입력
    (프로젝트 이름이 서브도메인이 되므로 openclassreport.pages.dev 가 자동으로 생성됩니다)
  5. 파일 업로드: 본 애플리케이션의 index.html (또는 dist 폴더 전체)를 업로드 영역으로 드래그
  6. 배포: 사이트 배포 (Deploy site) 클릭 시 배포가 완료되며, 브라우저에서 https://openclassreport.pages.dev 로 즉시 접속 가능합니다!
방법 2: GitHub 연동 자동 배포 (코드 수정 시 자동 반영)
  1. 본 프로젝트 코드를 본인의 GitHub 리포지토리에 푸시(Push)합니다.
  2. Cloudflare Pages에서 Git에 연결 (Connect to Git) 선택 후 해당 리포지토리 지정
  3. 프로젝트 이름: openclassreport
  4. 빌드 명령: npm run build / 빌드 출력 디렉터리: dist
  5. 저장 및 배포를 누르면 이후 GitHub에 push할 때마다 자동으로 최신 사이트가 반영됩니다.
