🔥 현재 Firebase 설정 상태

Firebase 프로젝트 설정값(firebaseConfig)을 연동하시면 클라우드 Firestore에 데이터가 영구 보존됩니다.
연동 전이어도 브라우저 로컬 저장소를 통해 엑셀 업로드, 시간표 수정, 참관록 작성이 100% 정상 작동합니다.

💡 브라우저에서 바로 Firebase Config JSON 적용하기

HTML 소스코드를 직접 수정하지 않고도 여기서 바로 본인의 Firebase Config 객체를 붙여넣어 연결할 수 있습니다.

🔥 Firebase (Firestore) 연동 가이드

이 웹앱은 Firebase Firestore와 손쉽게 연동할 수 있도록 Firebase JS SDK(CDN 호환)로 제작되었습니다. 아래 3단계를 따라 설정하시면 3분 안에 클라우드 데이터베이스와 연결됩니다.

(1) Firebase 콘솔에서 새 프로젝트 생성하는 방법
  1. 웹 브라우저에서 Firebase 콘솔(console.firebase.google.com)에 접속하여 Google 계정으로 로그인합니다.
  2. [+ 프로젝트 추가] 버튼을 누릅니다.
  3. 프로젝트 이름(예: open-class-2026 또는 학교명)을 입력하고 [계속]을 누릅니다.
  4. Google 애널리틱스 설정은 선택사항(체크 해제 권장)이며 [프로젝트 만들기]를 클릭하면 약 10초 후 완료됩니다.
(2) Firestore Database를 테스트 모드로 생성하고 컬렉션 구조 잡기
  1. 콘솔 좌측 메뉴에서 [빌드] > [Firestore Database]를 선택하고 [데이터베이스 만들기]를 누릅니다.
  2. 데이터베이스 위치를 선택(예: asia-northeast3 (서울) 권장)하고 [다음]을 누릅니다.
  3. 보안 규칙 단계에서 [테스트 모드에서 시작]을 선택하고 [사용 설정]을 클릭합니다.
  4. 컬렉션 구조 안내:
    • classes (수업 시간표 컬렉션): 문서 ID를 {학년}_{반}_{교시} 형식(예: 1_2_2)으로 과목(subject)과 교사(teacher)를 보관합니다.
    • observations (학부모 참관록 컬렉션): 학년(grade), 반(classNum), 교시(period), 과목(subject), 교사(teacher), 소감(content), 작성일시(createdAt)가 자동 저장됩니다.
    • settings (학교 정보 컬렉션): 학교명(schoolName), 행사명(eventTitle)을 저장합니다.
    * 컬렉션은 앱에서 첫 데이터 저장 시 Firestore가 자동으로 생성하므로 직접 수동으로 만드실 필요가 없습니다!
(3) 웹 앱 추가로 firebaseConfig 얻는 방법과 코드 붙여넣기
  1. Firebase 콘솔 홈(프로젝트 개요)으로 이동하여 중앙의 웹 아이콘 ( </> )을 클릭합니다.
  2. 앱 닉네임(예: 학부모참관록)을 입력하고 [앱 등록]을 클릭합니다.
  3. 화면에 표시되는 firebaseConfig 객체 코드를 복사합니다: 
    const firebaseConfig = {
  apiKey: "여기에_API_KEY",
  authDomain: "여기에_AUTH_DOMAIN",
  projectId: "여기에_PROJECT_ID",
  storageBucket: "여기에_STORAGE_BUCKET",
  messagingSenderId: "여기에_SENDER_ID",
  appId: "여기에_APP_ID"
};
  4. 코드 붙여넣을 위치:

    이 파일(index.html)의 <script> 태그 최상단에 있는 const firebaseConfig = { ... }; 부분의 큰따옴표 안에 복사한 실제 값들을 그대로 바꿔 넣으시면 됩니다. 또는 화면 상단 [⚙️ 관리자 확인란] > [Firebase 설정] 탭의 입력창에 붙여넣어 즉시 적용하실 수도 있습니다!
